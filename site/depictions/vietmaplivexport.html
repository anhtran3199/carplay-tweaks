VietmapLiveExport

Đọc tốc độ hiện tại + giới hạn tốc độ từ Vietmap Live (hook FlutterMethodChannel, API công khai của Flutter) và chia sẻ cho SplitCarPlay hiển thị trên CarPlay.

Cần cài cùng SplitCarPlay. Và cần bật chế độ ghi log cuộc gọi (notifyutil -p com.example.vietmaplivexport/toggle-logging) một lần để xác nhận đúng tên field dữ liệu trên phiên bản Vietmap Live bạn đang dùng — xem README trong repo.
